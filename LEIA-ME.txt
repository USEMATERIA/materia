MATÉRIA — pacote do site atualizado a partir do backup enviado

IMPORTANTE: este pacote preserva a identidade visual do index.html do backup (fundo areia, azul profundo, tipografia editorial e imagens/arquivos originais). O index(1).html foi mantido apenas como referência/backup.

Para publicar no GitHub Pages:
1. Extraia este ZIP no computador.
2. Envie os arquivos e imagens para a raiz do repositório, substituindo os arquivos antigos quando solicitado.
3. Garanta que index.html fique na raiz do repositório publicado.
4. Não envie apenas o ZIP.
5. Em Settings > Pages, confira a branch/pasta usada na publicação e depois confira Actions para ver se publicou com sucesso.

Páginas: index.html, mare.html, brisa.html, brasa.html e raiz.html.

Os botões de pedido montam um resumo e permitem copiá-lo; a finalização ainda é feita manualmente pelo Instagram. Não há checkout ou pagamento integrado. Preços usados: difusor R$119,90; home spray R$99,90; água para lençóis R$79,90. Confirme os valores antes de publicar.
